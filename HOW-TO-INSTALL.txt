=====================================================================
  HANDTRACK ДЛЯ LINUX — ПОШАГОВАЯ УСТАНОВКА
  (English version below)
=====================================================================

HandTrack распознаёт жесты рук, может скрыть ваше лицо, рисовать в воздухе
и показывает всё это в звонках через виртуальную камеру «HandTrack Camera»
(Discord, Telegram, Zoom, Google Meet в браузере, OBS).

Нужно: Ubuntu 22.04+, Debian 12+, Fedora 39+, Linux Mint 21+, Arch или
openSUSE (64-бит: x86_64 или ARM64), веб-камера, интернет на время установки.


---------------------------------------------------------------------
ШАГ 1. СКАЧАЙТЕ
---------------------------------------------------------------------

  Вариант А (проще): страница Releases -> handtrack-linux-x86_64.tar.gz
  Вариант Б: зелёная кнопка «Code» -> «Download ZIP».
             Установщик сам скачает всё нужное (2-5 минут).


---------------------------------------------------------------------
ШАГ 2. РАСПАКУЙТЕ
---------------------------------------------------------------------

  Правой кнопкой по архиву -> «Извлечь сюда» (Extract Here).
  В папке будут:
       install.sh            <- установщик
       uninstall.sh          <- удаление
       HOW-TO-INSTALL.txt    <- эта инструкция
  Права на запуск у файлов уже есть — ничего настраивать не нужно.


---------------------------------------------------------------------
ШАГ 3. ЗАПУСТИТЕ УСТАНОВЩИК
---------------------------------------------------------------------

  1. Запустите install.sh одним из способов:
       - KDE, XFCE, Cinnamon, MATE: двойной щелчок по install.sh
         (если спросит — «Выполнить» / «Run»);
       - GNOME (Ubuntu, Fedora): правой кнопкой по install.sh ->
         «Запустить как программу» (Run as a Program);
       - или правой кнопкой по пустому месту в папке -> «Открыть
         в терминале» и введите:   ./install.sh

  2. Откроется терминал с шагами установки. Он попросит пароль —
     введите пароль от вашего компьютера и нажмите Enter.
     ПРИ ВВОДЕ ПАРОЛЬ НЕ ОТОБРАЖАЕТСЯ — ЭТО НОРМАЛЬНО.
     Пароль нужен один раз: чтобы установить виртуальную камеру.

  3. Когда появится «ГОТОВО», HandTrack запустится сам.
     Дальше открывайте его из меню приложений: HandTrack.


---------------------------------------------------------------------
ШАГ 4. ПОЛЬЗУЙТЕСЬ
---------------------------------------------------------------------

  1. Нажмите «СТАРТ» — появится изображение с камеры.
  2. Включите «Транслировать в виртуальную камеру».
  3. В Discord / Telegram / Zoom / браузере выберите камеру
     «HandTrack Camera». Если её нет — перезапустите это приложение.

  * «Скрыть лицо» — чёрная маска на лице и значок COVERING.
  * Рисование: соедините большой и указательный пальцы и ведите рукой.
  * «Мои жесты» — комбинация пальцев -> клавиши, музыка, программы.
    (Клавиши работают в сеансе X11; в Wayland часть систем их блокирует.)


---------------------------------------------------------------------
УДАЛЕНИЕ
---------------------------------------------------------------------

  Любой способ:
    * меню приложений -> «Удалить HandTrack»;
    * в терминале:  handtrack-uninstall
    * или запустите uninstall.sh из этой папки.
  Он спросит, удалять ли настройки и виртуальную камеру.


---------------------------------------------------------------------
ЕСЛИ ЧТО-ТО НЕ ТАК
---------------------------------------------------------------------

  * Установщик пишет про Secure Boot: модуль камеры (v4l2loopback) не
    подписан. Варианты:
      - Ubuntu: во время установки пакета вас попросят придумать пароль
        MOK; после перезагрузки на синем экране выберите «Enroll MOK»
        и введите его;
      - или выключите Secure Boot в настройках BIOS/UEFI.
    Сама программа работает и без камеры для звонков.
  * Камеры «HandTrack Camera» нет после перезагрузки — откройте HandTrack
    -> Настройки -> «Установить драйвер».
  * Окно не открывается: в терминале выполните  handtrack  и посмотрите
    ошибку. Журнал: ~/.config/handtrack/logs/handtrack.log
  * Журнал установки: /tmp/handtrack-install.log


=====================================================================
  HANDTRACK FOR LINUX — STEP BY STEP
=====================================================================

You need a 64-bit Ubuntu 22.04+, Debian 12+, Fedora 39+, Mint 21+, Arch or
openSUSE, a webcam and internet during setup.

1. DOWNLOAD: Releases -> handtrack-linux-x86_64.tar.gz
   (or "Code" -> "Download ZIP"; the installer downloads the rest).
2. EXTRACT: right-click -> "Extract Here". The files are already executable.
3. INSTALL: double-click install.sh (GNOME: right-click -> "Run as a Program",
   or "Open in Terminal" and type ./install.sh). Type your password when asked —
   it is not shown while typing. It is needed once, for the virtual camera.
4. USE: press START, enable "Stream to virtual camera", pick
   "HandTrack Camera" in your call app (restart the app if it is missing).
UNINSTALL: app menu -> "Uninstall HandTrack", or run  handtrack-uninstall.
SECURE BOOT: the camera module must be signed (enroll the MOK key when Ubuntu
asks, or turn Secure Boot off). The app itself works without it.
