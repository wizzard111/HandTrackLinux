=====================================================================
  HANDTRACK FOR LINUX — STEP BY STEP
=====================================================================

HandTrack recognises hand gestures, can hide your face, lets you draw
in the air and shows all of it in your calls through the virtual camera
"HandTrack Camera" (Discord, Telegram, Zoom, Google Meet in a browser,
OBS).

You need: Ubuntu 22.04+, Debian 12+, Fedora 39+, Linux Mint 21+, Arch or
openSUSE (64-bit: x86_64 or ARM64), a webcam, internet during setup.


---------------------------------------------------------------------
STEP 1. DOWNLOAD
---------------------------------------------------------------------

  Option A (simpler): Releases page -> handtrack-linux-x86_64.tar.gz
  Option B: the green "Code" button -> "Download ZIP".
            The installer then downloads what it needs (2-5 minutes).


---------------------------------------------------------------------
STEP 2. EXTRACT
---------------------------------------------------------------------

  Right-click the archive -> "Extract Here".
  The folder contains:
       install.sh            <- the installer
       uninstall.sh          <- the uninstaller
       HOW-TO-INSTALL.txt    <- this guide
  The files are already executable; nothing to set up.


---------------------------------------------------------------------
STEP 3. RUN THE INSTALLER
---------------------------------------------------------------------

  1. Start install.sh in one of these ways:
       - KDE, XFCE, Cinnamon, MATE: double-click install.sh
         (choose "Run" if asked);
       - GNOME (Ubuntu, Fedora): right-click install.sh ->
         "Run as a Program";
       - or right-click an empty spot in the folder -> "Open in
         Terminal" and type:   ./install.sh

  2. A terminal shows each installation step. It asks for a password:
     type your computer password and press Enter.
     THE PASSWORD IS NOT SHOWN WHILE YOU TYPE. THAT IS NORMAL.
     It is needed once, to install the virtual camera.

  3. When the terminal says DONE, HandTrack starts by itself.
     Later, open it from the application menu: HandTrack.


---------------------------------------------------------------------
STEP 4. USE IT
---------------------------------------------------------------------

  1. Press "Start": the camera picture appears.
  2. Switch on "Stream to virtual camera".
  3. In Discord / Telegram / Zoom / the browser choose the camera
     "HandTrack Camera". Not listed? Restart that app.

  * "Hide face" puts a black mask over your face and shows a
    COVERING badge.
  * Drawing: pinch your thumb and index finger together and move
    your hand.
  * "My gestures": a finger combination -> keys, music, programs.
    (Keys work in an X11 session; some Wayland desktops block them.)
  * Ctrl + Alt + H switches "Hide face" on and off from any program
    (in an X11 session; Wayland does not allow global hotkeys). Change
    it in Settings.


---------------------------------------------------------------------
UNINSTALL
---------------------------------------------------------------------

  Any of these:
    * application menu -> "Uninstall HandTrack";
    * in a terminal:  handtrack-uninstall
    * or run uninstall.sh from this folder.
  It asks whether to delete your settings and the virtual camera.


---------------------------------------------------------------------
IF SOMETHING GOES WRONG
---------------------------------------------------------------------

  * The installer mentions Secure Boot: the camera module
    (v4l2loopback) is not signed. Either:
      - Ubuntu: while the package installs you are asked to choose a
        MOK password; after the restart pick "Enroll MOK" on the blue
        screen and type it;
      - or turn Secure Boot off in the BIOS/UEFI settings.
    The app itself works without the call camera.
  * No "HandTrack Camera" after a restart — open HandTrack ->
    Settings -> "Install driver".
  * The window does not open: run  handtrack  in a terminal and read
    the error. Log: ~/.config/handtrack/logs/handtrack.log
  * Something broke or went missing — just run the installer again.
    It checks what is missing and installs only that, without
    downloading or overwriting anything else.
  * Install log: /tmp/handtrack-install.log
